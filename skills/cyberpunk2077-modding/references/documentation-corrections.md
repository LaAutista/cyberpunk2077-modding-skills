# Corrections and version traps in upstream documentation

These original notes preserve findings from the October 2026 source review. Pinned implementation links identify the inspected revisions; current upstream pages may have been corrected since then. Recheck the installed version before adapting an example. Source inspection and Lua checks are not game acceptance.

| Source/example | Finding | Use when implementing |
| --- | --- | --- |
| [CET `onUpdate`](https://wiki.redmodding.org/scripting-cyberpunk/cyber-engine-tweaks/cet-functions/events/onupdate) describes milliseconds | The fetched [CET implementation](https://github.com/maximegmd/CyberEngineTweaks/blob/bcbe4574102c12e9f88218f6a7e881edd9aadca4/src/scripting/LuaVM_Hooks.cpp) converts elapsed time to `std::chrono::duration<float>` seconds, passes `cSeconds.count()` to `Update`, and forwards it unchanged to the Lua callback in [ScriptContext.cpp](https://github.com/maximegmd/CyberEngineTweaks/blob/bcbe4574102c12e9f88218f6a7e881edd9aadca4/src/scripting/ScriptContext.cpp). | Treat `deltaTime` as seconds for this source revision. Check the installed version if its implementation differs. |
| [CET Good Practices](https://wiki.redmodding.org/scripting-cyberpunk/cyber-engine-tweaks/first-steps/good-practices) says `string.match` returns the input on no match | Lua returns `nil`; confirmed in the [Lua 5.1 manual](https://www.lua.org/manual/5.1/manual.html#pdf-string.match) and by running local LuaJIT. | Test the result for `nil`/truthiness. |
| Same page treats `dog\|cat` as alternation | Lua patterns do not provide regex alternation with `\|`; the pipe is literal. Confirmed in the [pattern reference](https://www.lua.org/manual/5.1/manual.html#5.4.1) and local LuaJIT. | Use two pattern tests or a proper alternative appropriate to the input. For literal substring search, `string.find(text, needle, 1, true)` avoids pattern interpretation. |
| Same page makes broad performance claims about string literals and early returns | These claims are not established by the example. The illustrated `for (_, ...)` loop is also not valid Lua syntax. | Write valid, readable Lua and measure the actual hot path; do not adopt these claimed percentages as facts. |
| [CET `onOverlayClose`](https://wiki.redmodding.org/scripting-cyberpunk/cyber-engine-tweaks/cet-functions/events/onoverlayclose) first example registers `onOverlayOpen` | The event name contradicts the intended close example. | Register `onOverlayClose` for close behavior. The combined example below it uses both names correctly. |
| [WolvenKit Projects](https://wiki.redmodding.org/wolvenkit/wolvenkit-app/usage/wolvenkit-projects) CET resource path | The table contains `cyber_engine/tweaks/mod`. | Use `bin/x64/plugins/cyber_engine_tweaks/mods/<ModName>/init.lua`, as in CET's installation/layout and the local game. |
| [How to create a hook](https://wiki.redmodding.org/scripting-cyberpunk/redscript/getting-started/how-to-create-a-hook) helper example | A newly introduced `RagdollNPC` helper is shown as `@wrapMethod`. Another example calls `npc.GetEntityID()` before its validity guard. | Confirm whether a method already exists; use `@addMethod` or your own class for a new helper. Guard the downcast before dereferencing it. |
| [InkWidgets Basics](https://wiki.redmodding.org/scripting-cyberpunk/scripting/game-systems/ui-scripting/inkwidgets-basics) animation snippet | Declares `anim` but passes an undeclared `tickAnim` to `AddInterpolator`. | Pass the created interpolator (`anim`) and verify the surrounding APIs on the target version. |
| [Codeware wiki](https://github.com/psiberx/cp2077-codeware/wiki) uses `Entity/Attached` in some examples | The source marks it deprecated and maps it to `Entity/AfterAttach` in [EntityAttachHook.hpp](https://github.com/psiberx/cp2077-codeware/blob/613a1cb830ecf33508ffca839d3ea631073504ef/src/App/Callback/Controllers/EntityAttachHook.hpp). | Use `Entity/AfterAttach` for the post-attach event in new code; `Entity/Attach` occurs before the underlying attach. |
| [ArchiveXL visual-tag table](https://github.com/psiberx/cp2077-archive-xl/wiki#visual-tags) describes `hide_Arms` as hiding the head | The [shipped VisualTags.xl](https://github.com/psiberx/cp2077-archive-xl/blob/5474e34d56112f5d8843ae863e1e72ff510957c0/bundle/source/resources/VisualTags.xl) maps it to `a0_`, `left_arm`, and `right_arm`. | Treat it as an arm-hiding tag. |
| [WolvenKit File Validation](https://wiki.redmodding.org/wolvenkit/wolvenkit-app/file-validation) mentions `DynamicAppearances` | The [ArchiveXL reference](https://github.com/psiberx/cp2077-archive-xl/wiki#how-to-activate) specifies singular `DynamicAppearance`. | Use the actual ArchiveXL visual-tag spelling and check the implementation if uncertain. |
| [redscript troubleshooting](https://wiki.redmodding.org/scripting-cyberpunk/redscript/help/troubleshooting) points at `r6/cache/redscript.log` | The current [compiler README](https://github.com/jac3km4/redscript/blob/3ca666c8ec14cfc803ef3888aab6ebc7a1c2bb86/README.md) points at `r6/logs/redscript_rCURRENT.log`. | Inspect the logs produced by the installed compiler; do not conclude it failed because an older path is absent. |

Examples are explanations, not compiled acceptance tests. Some guides target older game/framework releases; labels such as “latest stable” inside archived wiki pages are not a current version check. The REDmod PDF is the official 2022 manual and should be treated as a description of that tool's documented flow. The old redscript wiki is deprecated; begin new scripting work in Scripting Cyberpunk and consult the compiler/framework source when the documents disagree.
