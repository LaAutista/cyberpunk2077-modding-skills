# Source adapter contract

Cyberpunk 2077 remains the destination. Shared destination stages are rig/component
adaptation, full-motion/contact inspection, audio/event translation, native export,
readback, package validation and user-controlled gameplay. A source adapter supplies
source inventory, format decoding, reference/graph recovery and exchange validation.
Do not duplicate destination stages or install tools for an unused source.

`ron-hk416.json` is the first bounded evidenced adapter. Its historical successful
extraction is distinct from this setup candidate's fixture checks. Resolve its guide
and helper paths relative to the manifest directory. Dependencies are scoped to source
extraction versus later destination stages. Audio is optional and needs its separate
FMOD inputs and task framework requirements.

To add a future source, provide a separate manifest, guide and adapter containing:

- exact installed build, formats/codecs and sample identities/hashes;
- pinned tool/source versions, transitive dependencies, patches and authoritative origins;
- supplied input boundaries and isolated output paths;
- source animation/additive/graph/event/audio semantics and conversion losses;
- repeatable positive/negative checks, actual evidence and untested cases;
- experimental status until the source exchange and destination gates have evidence.

A source game's engine or similar filenames do not prove a compatible adapter.
Future Halo, Tarkov or other Unreal workflows are not implemented by this contract.
